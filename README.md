# 🎉 Ballermann-Hitster

Ein privates, digitales **Hitster-Klon-Spiel** für Ballermann- und Party-Hits. Spiele im **Hotseat-Modus** (mehrere Spieler, ein Gerät) und ordne Songs chronologisch in eine Timeline ein – mit automatischen 30-Sekunden-Vorschauen von iTunes.

**Live spielen:** https://silvihi11.github.io/ballermann-hitster/

---

## 🎮 Wie funktioniert's?

### Spielprinzip
1. **Spieler einrichten:** Gib die Namen aller Spieler ein und wie viele Karten man zum Sieg braucht
2. **Song ziehen:** Klick "Nächsten Song ziehen" → die App sucht automatisch eine 30-Sekunden-Vorschau von iTunes
3. **Raten & Ziehen:** Höre den Song an und zieh die geheime Karte per **Drag & Drop** an die richtige Stelle in der chronologischen Timeline
4. **Auflösen:** Klick "Auflösen" → wenn dein Jahr richtig ist (oder zwischen den Nachbarn passt), bekommst du die Karte. Sonst geht's zum nächsten Spieler
5. **Gewinnen:** Wer zuerst die eingestellte Kartenanzahl erreicht, gewinnt! 🏆

### Besonderheiten
- 🎵 **iTunes-Integration:** Automatische 30-Sekunden-Vorschauen (kostenlos, keine API-Keys nötig)
- 📱 **Responsive Design:** Funktioniert auf Desktop, Tablet und Handy
- 🎯 **Hotseat-Modus:** Perfekt für Partys – ein Gerät, mehrere Spieler
- 🎨 **Ballermann-Theme:** Gelbe Karten, dunkler Hintergrund, Party-Vibes
- 💾 **Offline-Ready:** Nach dem ersten Laden funktioniert die App auch ohne Internet (nur die Song-Suche braucht kurz eine Verbindung)

## 🚀 So spielst du

### Desktop/Laptop
1. Öffne https://silvihi11.github.io/ballermann-hitster/ im Browser
2. Spielernamen eingeben
3. "Spiel starten" klicken
4. Viel Spaß! 🎉

### iPad/iPhone
1. Öffne Safari
2. Gib die URL ein: https://silvihi11.github.io/ballermann-hitster/
3. Speichere die Seite als Lesezeichen oder füge sie zum Home-Screen hinzu (Share → "Zum Home-Bildschirm")
4. Spielen wie auf dem Desktop

## ⚙️ Technische Details

- **Frontend:** Vanilla JavaScript (HTML5, CSS3)
- **Musik-API:** iTunes Search API (kostenlos, keine Authentifizierung)
- **Hosting:** GitHub Pages
- **Browser-Kompatibilität:** Chrome, Safari, Firefox, Edge (alle modernen Versionen)
- **Offline-Fähigkeit:** Ja (nach dem ersten Laden)

### Was passiert, wenn kein iTunes-Preview gefunden wird?
- Die App zeigt eine Nachricht an
- Du kannst den Song selbst summen 🎤 oder auf YouTube/Spotify nachschlagen
- Das Spiel geht normal weiter

## 📋 Regeln

- **Karten zum Sieg:** Stellbar (Standard: 10)
- **Richtig platziert:** Die Karte muss chronologisch zwischen den Nachbarn passen
- **Hotseat:** Jeder Spieler zieht reihum einen Song
- **Gewinner:** Wer zuerst die eingestellte Kartenanzahl erreicht

## 🎵 Musikquellen

- Alle Songs sind echte Ballermann-/Party-Klassiker
- Jahre sind recherchiert und verifiziert
- Previews kommen von der iTunes-API (30 Sekunden)
- Funktioniert mit allen iTunes-Accounts (kostenlos & Premium)
